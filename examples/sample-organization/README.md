# Sample Organization Examples

This fictional dataset illustrates how one organization can compose shared Agent Caravan defaults into distinct product teams.

These Markdown artifacts are readable illustrations, not a loadable JSON catalog.
Adding this directory to profile `sources` does not load the Markdown files.
For runnable JSON artifacts and profile sources, use the
[coworker-sharing scenario](../coworker-sharing/README.md) and its
[example organization catalog](../example-organization/organizations/example-organization-catalog.json).

- `organizations/`: artifact publication boundary
- `domain-knowledge/`: broad product context
- `caravans/`: durable ownership boundaries
- `capability-knowledge/`: team-owned knowledge
- `configuration-overrides/`: scoped role customization
- `runtime-mappings/`: Codex runtime bindings
- `resolved/`: explainable resolved-view example

All product names, sources, and URLs are fictional placeholders. These examples do not prescribe an organization structure.
