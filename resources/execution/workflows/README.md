# Execution Workflows

This directory contains reusable machine-readable execution-profile artifacts.
Workflows define activation, topology, handoffs, termination, escalation, and
policy references without requiring a particular orchestration engine.

`information-technology-core-team-basic-work.json` is the starter workflow. It
does not select organization policies or require evidence/audit records.
`information-technology-core-team-feature-delivery.json` is an opt-in advanced
workflow with explicit safety-policy and evidence requirements.
