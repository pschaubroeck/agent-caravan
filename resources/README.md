# Resources

Resources are organized by ownership boundary:

- `core/`: reusable roles and caravan templates
- `execution/`: workflows, state templates, handoffs, and policies
- `runtime/`: runtime integrations and runtime mappings
- `schemas/`: machine-readable contract shapes
- `specifications/`: normative runtime-neutral framework contracts

Organization-specific reference examples remain under `examples/` and are not
required by the foundation.
